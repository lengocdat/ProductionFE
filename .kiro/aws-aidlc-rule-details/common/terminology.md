# Terminology Guide

**Purpose**: Define key terms used throughout the workflow.

## AI-DLC Terms

| Term | Definition |
|------|-----------|
| **Phase** | Major workflow section (Inception, Construction, Operations) |
| **Stage** | Individual step within a phase (e.g., Requirements Analysis) |
| **Unit** | A decomposed piece of work for implementation |
| **Brownfield** | Project with existing code |
| **Greenfield** | New project from scratch |
| **Gate** | Approval checkpoint — cannot proceed without user confirmation |

## Element System (Ngũ Hành)

```
Kim (Metal) → khắc Mộc (Wood)
Mộc (Wood) → khắc Thổ (Earth)
Thổ (Earth) → khắc Thủy (Water)
Thủy (Water) → khắc Hỏa (Fire)
Hỏa (Fire) → khắc Kim (Metal)
```

Advantage multiplier: 1.5x damage
