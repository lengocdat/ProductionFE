# Session Continuity Guide

**Purpose**: Guide for resuming work across sessions.

## How to Resume

When starting a new session:

1. **Check `aidlc-docs/aidlc-state.md`** for current progress
2. **Read the current stage's artifacts** to understand where we left off
3. **Check `aidlc-docs/audit.md`** for last interaction context
4. **Load relevant rule-details** for the current stage

## State File Location
- `aidlc-docs/aidlc-state.md` — master state tracking
- `aidlc-docs/audit.md` — interaction history

## Thiên Đạo Game Session Context

When resuming, also check:
- `deep-research-report.md` — full game design reference
- `ThienDaoGame/` — backend code state
- `ThienDaoGameFE/` — frontend code state
- `game_config.json` — current game balance parameters

## Resume Checklist
- [ ] Read aidlc-state.md for current stage
- [ ] Read last 20 lines of audit.md for context
- [ ] Load rule-details for current stage
- [ ] Check if any approval is pending
- [ ] Continue from where we left off
